About
CodeFix Pro runs entirely in your browser. HTML, CSS and JavaScript run for real inside a sandboxed iframe (no access to this page, cookies or storage). Other languages need a compiler or interpreter on a server; this version has no such server, so for them it only does a basic structural check (brackets, quotes, Python colons) and never pretends to run your code.
